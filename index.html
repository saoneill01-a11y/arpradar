Names, not just numbers

ARPradar asks every device the ways devices answer, so the list reads like an inventory instead of a column of IP addresses.

Who's there

ping · TCP knock · ARP

Finds devices that ignore ping, reads each MAC address and names the manufacturer.

What they're called

NetBIOS · Bonjour · DNS · UPnP

Windows PCs, Macs, printers, TVs and smart plugs name themselves. Point it at a client's domain controller for its DNS names.

What they are

SNMP · web page titles · banners

Switches, access points and UPSes report their model. Web admin pages give away the rest.

What's open

22 · 80 · 443 · 445 · 3389 …

Common ports on every device, or right-click any one to check all 65,535.

What changed

NEW · offline · history

Saved scans remember their devices. Rescan and new arrivals are tagged, missing ones show in red.

What to do next

browser · shares · SSH · RDP · VNC

Right-click to open a device's web page, its shares in Finder, a remote session, or wake it on LAN.

The rest of the toolkit

The checks you'd otherwise open five apps for, in one Tools menu.

  • Traceroute⌘2Every hop to a host, with names and times.

Install on a Mac

About a minute. No installer, no account.

  1. DownloadGet ARPradar.zip from the latest release and open it.
  2. Move it to ApplicationsDrag ARPradar into your Applications folder.
  3. Open it the first timeDouble-click ARPradar. If macOS stops it, see the note on the right.
  4. Allow Local NetworkClick Allow when macOS asks, so ARPradar can reach devices on your network.

“ARPradar can’t be opened”

Until the app is signed by Apple, macOS asks you to confirm it once. Open System Settings › Privacy & Security, scroll down, and click Open Anyway next to ARPradar.

For Wi-Fi network names, macOS also asks for Location. ARPradar never reads your location; it's how macOS guards Wi-Fi names.

Install on Windows

An early version: most of the Mac app's features, still being tested.

  1. DownloadGet ARPradar-Windows-setup.exe from the latest release.
  2. Run the installerDouble-click it and follow the steps. It installs for you only, no admin needed.
  3. ScanOpen ARPradar from the Start menu and press Scan.

“Windows protected your PC”

Until the app is signed, SmartScreen warns you once. Click More info, then Run anyway.
