# ARPradar

Free network scanner for macOS. Website: **https://arpradar.com**

**Download:** [ARPradar.zip](https://github.com/saoneill01-a11y/arpradar/releases/latest/download/ARPradar.zip) (macOS 14 Sonoma or later, Apple silicon and Intel).

ARPradar sweeps a network in about ten seconds and names every device: maker, open ports, shares, web pages. Save scans per client, rescan later and see what changed, and use the built-in Ping, Traceroute, DNS Lookup, Wi-Fi Analyzer, Speed Test and Subnet Calculator.

## Install
1. Download `ARPradar.zip` from the [latest release](https://github.com/saoneill01-a11y/arpradar/releases/latest) and open it.
2. Drag ARPradar into Applications and open it.
3. If macOS says it can't be opened: System Settings › Privacy & Security › **Open Anyway**. (Needed until the app is signed by Apple.)
4. Click **Allow** for Local Network.

This repository holds the website (`index.html`, served by GitHub Pages at arpradar.com) and the downloads (Releases).
